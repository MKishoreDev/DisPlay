## 2. No Credential Access & Security Architecture

- **No Credential Collection**: DisPlay does **NOT** request, store, transmit, or handle Discord account tokens, user passwords, cookies, or private user data.
- **No Token Hijacking or API Exploits**: DisPlay does **NOT** perform token automation, internal API manipulation, DLL injection, or memory modification.
- **Local OS Process Spoofing**: DisPlay operates strictly by instantiating standard local OS process image names (e.g., `endfield.exe`, `league of legends.exe`). Discord Desktop's public process scanner inspects standard OS process tables (`tasklist` / `ps`) to register game activity.

---

## 3. Mission Rationale & Video/Ad Quest Exclusion

- **Bandwidth Preservation**: DisPlay is created specifically to save gigabytes of bandwidth wasted on downloading **50 GB – 100 GB game clients** for games you don't even play, simply to leave them open for 15 minutes to claim a quest reward.
- **Video & Ad Quests Excluded**: Video, stream, and promotional ad quests (1 – 5 minute ads) are intentionally excluded. No user is too busy to watch a short ad; DisPlay is specifically against wasting data downloading massive game installations just for 15-minute opening requirements.

---

## 4. Usage Recommendations

- **Author Recommendation**: The author recommends allowing a 5–10 minute break between completing consecutive game quests. This is a personal operational recommendation and not a system-enforced lock within the application.
- **Compliance**: Users are encouraged to stay informed regarding platform policies and terms of service.
