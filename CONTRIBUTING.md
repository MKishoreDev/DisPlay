# 🤝 Contributing to DisPlay

Thank you for your interest in contributing to **DisPlay**!

---

## 📋 Guidelines

1. **Clean Code** — Follow PEP 8 style. Keep functions focused and well-documented.
2. **Zero Dependencies** — DisPlay must remain zero-dependency (Python standard library only). The `requests` library is an optional enhancement, never required.
3. **No Exploits** — Contributions must use OS-level process management only. No token scraping, API abuse, client patching, or automation.
4. **Cross-Platform** — All code must work on Windows, Linux, and macOS at minimum.

---

## 🛠️ How to Contribute

```bash
# Fork the repo, then:
git clone https://github.com/<your-username>/DisPlay.git
cd DisPlay
git checkout -b feature/your-feature

# Make your changes, then:
git add .
git commit -m "Add: your feature description"
git push origin feature/your-feature
```

Then open a **Pull Request** on GitHub for review.

---

## 🐛 Reporting Issues

Open a [GitHub Issue](https://github.com/MKishoreDev/DisPlay/issues) with:
- Your OS and Python version
- Steps to reproduce the bug
- Expected vs actual behavior
- Terminal output / error messages
